# FitQuest

The remastered Version of Fitapp

## Overview

FitQuest is a fitness application project designed to help users track and achieve their fitness goals.

## Getting Started

### Prerequisites

- [Visual Studio Code](https://code.visualstudio.com/) installed
- [GitHub Copilot](https://github.com/features/copilot) extension installed in VS Code

### Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/Jomophobeous/FitQuest.git
   cd FitQuest
   ```

2. Open the project in Visual Studio Code:
   ```bash
   code .
   ```

3. Install recommended extensions when prompted (including GitHub Copilot)

4. Start developing with GitHub Copilot assistance!

## VS Code Configuration

This project includes VS Code workspace settings optimized for development with GitHub Copilot:

- **Auto-formatting**: Files are automatically formatted on save
- **GitHub Copilot**: Enabled for all file types
- **Recommended Extensions**: GitHub Copilot and related tools
