# Dashboard Screen Context
# Load this before editing dashboard.

## Files (load these)
- app/dashboard.tsx — Screen UI, hero section, stat cards, CTA (933 lines)
- src/viewmodels/useDashboardViewModel.ts — All data loading (580 lines)

## Components
- src/components/dashboard/* — Dashboard-specific sub-components
- src/components/AnimatedFQLogoMark.tsx — Animated logo in header

## Data flow
useDashboardViewModel loads:
  → getAppState('user.display_name') → displayName (empty string default)
  → getUserProgress() → total_workouts, last_workout_date
  → getStreak() → current, longest
  → getMuscleFatigue() → fatigue levels
  → getXPData() → level, totalXP
  → getCachedReadiness() → readiness snapshot

## Key state
- displayName — from user.display_name app_state ('' if unset)
- greeting — typed animation: "Good morning" / "Good afternoon" / "Good evening"
- Hero title shows displayName in h2

## Conventions
- Greeting is typed with typewriter animation
- Stats row: numbers bigger than labels
- Glass cards for stat display
- Logo: AnimatedFQLogoMark with pulse glow
