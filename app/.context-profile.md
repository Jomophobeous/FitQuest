## Data flow
useProfileViewModel loads:
  → getUserProfile('user_local_001')
  → getAppState('user.display_name')
  → getStreak, getXPData, getUserProgress
  → Populates all profile data + handlers

## Key patterns
- Preferences use TouchableOpacity (NOT RippleButton — it breaks flex row)
- Pickers use ThemedPickerModal via setPickerModal({visible, title, options, onSelect})
- Name editing: handleSaveName → setAppState('user.display_name', trimmed)
- Language: handleLanguage → ThemedPickerModal → setLanguage(code)
- Training profile collapsed to single tappable row
- No sub-headers — icons are self-explanatory

## Sections (top to bottom)
1. ProfileHeader (avatar, name, email, XP)
2. Stats Grid (workouts, streak, level)
3. Training Profile (1 collapsed row)
4. Preferences GlassCard (theme, language, notifications, meal region, biometric, social, analytics)
5. Account Section (email, password, sign out, delete)
