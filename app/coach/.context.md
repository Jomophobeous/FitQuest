## Data flow
User types → sendMessage() → dispatchMessage(input)
  → intentRouter.classify() (fast path: navigation)
  → aiProvider.generateResponse(input, context)
    → authority gate (server check)
    → cloud chain (Groq → Grok → OpenRouter)
    → fallback: dualAI.query() (offline templates)
  → streamResponse() typewriter effect
  → setMessages() → FlatList renders bubble

## Key state
- coachCtxRef — workout context (streak, fatigue, readiness)
- messages — chat history (ChatMessage[])
- isTyping — shows typing indicator
- input — current text input
- activeSuggestions — follow-up chips
- userName — from getAppState('user.display_name') || ''
