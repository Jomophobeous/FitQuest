## Tab Screens (5)

### Dashboard (Home) — `app/dashboard.tsx`
- **Premium**: No
- **Purpose**: Central hub — XP level, recovery score, streak, fatigue map, quick actions, daily goals, workout history
- **Engines**: recoveryEngine, UserStateEngine, healthMonitor, ReadinessEngine
- **Services**: xpService, dataSyncService, rankingService
- **Data Flow**: SQLite → DatabaseContext → dashboard state → GlassUI rendering

### FitQuest AI Trainer — `app/fitquest.tsx`
- **Premium**: Yes — "AI Workout Generator"
- **Purpose**: AI-powered workout generation, exercise-by-exercise execution with audio coaching, set tracking, rep counting
- **Engines**: workoutGenerator, progressionEngine, recoveryEngine, warmupCooldownGenerator, edgeCaseGuards, SensorFusionEngine
- **Services**: xpService, timerService, audioService, exerciseImageService
- **Data Flow**: Profile + fatigue → workoutGenerator → session → timer/audio → completion → XP + snapshot

### Move (Steps & Jogging) — `app/move.tsx`
- **Premium**: No
- **Purpose**: Daily step tracking, jog sessions with GPS, distance/pace/calories, step history charts
- **Engines**: StepCounterEngine, SensorFusionEngine, DistanceEngine, HealthMonitor
- **Services**: locationService, dataSyncService
- **Data Flow**: Pedometer/GPS → step counter → SQLite daily_steps/jog_sessions → charts

### AI Coach — `app/coach/index.tsx`
- **Premium**: Yes — "AI Coach"
- **Purpose**: Conversational AI fitness coach with intent routing, form guidance, motivation, health Q&A
- **Engines**: DualAIEngine, IntentRouter, UserStateEngine
- **Services**: aiWorkoutService, aiProvider
- **Data Flow**: User query → IntentRouter → DualAI COACH personality → encrypted conversation storage

### Profile & Settings — `app/profile.tsx`
- **Premium**: No
- **Purpose**: User profile, stats dashboard, workout history, theme/language selection, backup/restore, subscription management
- **Engines**: RealisticHealthEngine, UserStateEngine
- **Services**: dataSyncService, backupService, socialLayerService, rankingService, xpService
- **Data Flow**: user_profile → display + app_state → preferences + subscription_state → tier
